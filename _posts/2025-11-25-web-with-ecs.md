This project creates a Web Application using the Amazon Web Services infrastructure.

The Web Application is created using Flask through a Python script. To serve this page, I've used Amazon's Elastic Container Service, Amazon Load Balancer, and some other services to support the main infrastructure, such as VPC, Secutiry Groups, Roles, Cloud Watch Log Group.
